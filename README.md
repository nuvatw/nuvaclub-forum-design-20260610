# nuvaClub Forum Design 20260610

Standalone UI/UX mock for the nuvaClub forum sharing flow.

## Features

- 72 mock forum posts: 24 `貼文`, 24 `問問題`, 24 `小作品`
- Composer flow with `貼文`, `問問題`, `小作品`
- `小作品` question mark tooltip: `什麼是小作品？`
- Clickable video popup for `https://www.youtube.com/watch?v=aG0ku2xCMgo`
- Filters for `24 小時`, `一週`, `一個月`, `全部`
- Sort by newest, oldest, heart count high-to-low, and heart count low-to-high

## Local Run

```bash
npm install
npm run dev
```

## Production Check

```bash
npm run build
npm run preview
```
